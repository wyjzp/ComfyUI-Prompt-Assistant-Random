# ComfyUI Prompt Assistant Random

简体中文 | [繁體中文](README.zh-TW.md) | [English](README.en.md)

这是 [yawiii/ComfyUI-Prompt-Assistant](https://github.com/yawiii/ComfyUI-Prompt-Assistant) 的个人改造版。

原项目提供提示词助手、标签面板、提示词优化、翻译、图像/视频反推等功能；原项目及本改造版遵循 [GNU GPL v3.0](LICENSE) 许可证。

## 本仓库新增功能

### 运行时随机提示词

在原有的“标签工具”按钮旁新增 **运行时随机提示词** 按钮。它不会改写提示词输入框中手动写好的固定内容；点击 ComfyUI 的 Queue / Run 后，才从选定范围随机抽取 **一条** 标签提示词，临时拼接进本次实际执行的文本。

因此下游节点和 Show Text 节点看到的是本次真正参与生图的完整提示词：

```text
固定提示词, 本次随机抽中的提示词
```

### 分层筛选随机范围

可以同时选中多个分类、分类下的标签、或标签下的具体提示词。所有最终被纳入的提示词合并为一个候选池，并只随机抽取一条。

- 选中分类、未继续选择下级：该分类下的所有提示词加入候选池。
- 选中分类后又选择部分标签：只使用所选标签下的提示词。
- 选中标签后又选择部分具体提示词：只使用所选的具体提示词。
- 可跨多个分类混合选择；最终仍只从总候选池抽取一条。

### 锁定本次随机结果

- **未锁定**：批量 Queue 的每一次执行都会重新抽取一条提示词。
- **锁定本次随机结果**：同一次 Queue 批次中的所有执行共用第一次抽中的同一条提示词；下一次重新点击 Queue 时再重新抽取。
